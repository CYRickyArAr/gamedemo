# 寂静病房 · 地图设计说明

> 目标体量：**4 分钟 / 双人 / 周期性猎杀**。以下所有结论都以此为前提。

## 1. 结论速览

| 项 | 结论 |
| --- | --- |
| 可玩楼层 | **1 层** |
| 外景 | **不做可进入外景**；只在入口做一段不可进入的雨棚/铁栅栏背景 |
| 单层尺寸 | 38×30 格（83.6 × 66.0 m），TILE = 2.2 m |
| 房间数 | **24 间**（4 街区 × 3 列 × 2 行） |
| 单间尺寸 | 6.6 ~ 8.8 m 见方 |
| 走廊 | 外环 2 格宽（4.4 m）+ 十字走廊 2 格宽 + 中央护士站 13.2×13.2 m |
| 主环路 | 6 个（外环 1、十字 2、护士站 1、街区内部 2） |
| 藏身点 | 30+ 个（柜子 / 隔帘 / 屏风 / 淋浴帘 / 停尸柜） |
| 实时光源 | 上限 18 个 + 每间房自发光灯罩 |
| 雾 | `FogExp2(0.019)`，有效视距约 50 m |

## 2. 为什么是 1 层

- **时间账**：4 分钟 ≈ 800 m 步程；单层完整扫图约 450~550 m，扣掉 4~6 次猎杀与迷路，实际可搜索时间约 150 s。再加一层会把一半时间花在楼梯上。
- **信息污染**：EMF 是穿墙定位，多层会产生"隔层蜂鸣"，直接破坏搜索逻辑。
- **AI 风险**：鬼的 A* 跨层需要楼梯口两段拼接，容易出现卡楼梯、隔层索敌、隔层抓人。
- **性能**：当前 18 个实时光源 + SSAO 已接近上限，双层会让 draw call 翻倍。

> 如果未来一定要做 2 层：每层 20×20 格、12 间房、中央 4×4 楼梯井、单局 300 s、HUD 显示楼层、EMF 只对同层生效。需要改：`generateHospital → generateFloor`、3D 导航网格、鬼/玩家带 `floor`、协议加 `floor` 字段、所有自检脚本双份。

## 3. 布局结构

```
┌───────────────────────────────┐
│  外环走廊（2 格宽，绕场一周）  │
│  ┌────────┬─────────┬──────┐  │
│  │ 病房区 │  手术区  │      │  │
│  │  (绿)  │  (冷蓝)  │      │  │
│  ├────────┼─────────┤ 十字 │  │
│  │ 停尸区 │  办公区  │ 走廊 │  │
│  │ (深蓝) │  (暖黄)  │      │  │
│  └────────┴─────────┴──────┘  │
│        中央护士站（地标）       │
└───────────────────────────────┘
```

- **四个街区**各 14×10 格（内部 12×8），再切 **3 列 × 2 行**，每街区 6 间房。
- **每间房 1~3 个门**；相邻房间之间额外开门，形成"房间内穿行"的微环。
- **出生点**：`(3,3)` 与 `(34,26)` 对角，直线约 85 m，保证开局不会互相看见。

## 4. 四类设计原则的落地

### 4.1 视线管理

- 60 根柱列（约每 8.8 m 一根）+ 顶部横梁（每 4 格）+ 4 处折叠屏风，切碎最长 78 m 的直道。
- 雾密度 0.019，把有效视距压到约 50 m。
- 每个房间至少有 1 个门洞/家具形成的暗角，威胁不会"凭空出现"。

### 4.2 环路（追逐）

- 外环 + 十字 + 护士站 + 街区内部 = 6 个主环，鬼和玩家都能绕后。
- 单门房间（储藏、部分停尸间）是**死胡同**，提供高风险高回报的藏身选择。

### 4.3 地标与分区

| 分区 | 地面色 | 灯光色 | 地标 |
| --- | --- | --- | --- |
| 病房区（西北） | 墨绿 | 冷白 | 3 床列 + 隔帘 |
| 手术区（东北） | 冷蓝 | 青白 | 双头手术灯 |
| 停尸区（西南） | 深蓝 | 冷蓝 | 遗体冷藏抽屉墙 |
| 办公区（东南） | 暖黄 | 琥珀 | 会议桌 + 白板 |
| 中央 | — | 暖橙 | 护士站值班台 |

### 4.4 安全区

中央护士站是唯一暖光地标，但不提供无敌：鬼在猎杀时仍可进入。它的作用是**方位锚点**与**节奏对比**，不是避难所。

## 5. 藏身点分布

- 病房：床间隔帘
- 储藏间：储物柜（2~3 个）
- 停尸间：停尸柜 + 储物柜
- 盥洗室：淋浴帘
- 手术室 / 值班室：器械柜 / 文件柜（本轮补充）
- 走廊：折叠屏风（4 处，带碰撞体）

**规则**：每类房间至少 1 个藏身点；走廊藏身点只做"临时躲鬼"，不参与"寻找对方"的主要路径。

## 6. 已知取舍

- 不做多层、不做可进入外景——用"窗外雨棚 + 铁栅栏"的背景贴图保留出口幻想。
- 房间数 24 是"4 分钟 + 24 s 猎杀"的上限；如果实测发现搜不完，优先把单局延长到 5 分钟，而不是砍房间。
- 实时光源硬上限 18 个，超出会被移除；新增灯必须替换旧灯，不能只加。
